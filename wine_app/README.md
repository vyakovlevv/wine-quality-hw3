# Выбор вина

Python 3.12. Проверено на Python 3.12.3.

Из папки `wine_app`:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Модель уже обучена. Рядом с `app.py` должны лежать `model.joblib`, `config.json` и `test.csv`.
Порог общий для всех вкладок. CSV-пример можно скачать во вкладке «CSV».

`st.cache_resource` хранит один объект модели для всех запусков приложения.
`st.cache_data` хранит данные и возвращает их копии, поэтому подходит для таблиц и вероятностей.
Без декоратора `joblib.load` заново читал бы модель с диска при каждом движении слайдера.
Вероятности на test кэшируются отдельно: от порога зависит только сравнение с ними.

Для публикации нужно загрузить эту папку в GitHub, открыть Streamlit Community Cloud,
выбрать репозиторий и файл `wine_app/app.py`, указать Python 3.12 и нажать Deploy.
Если файлы лежат в корне репозитория, путь будет просто `app.py`.
После запуска добавить ссылку в последнюю ячейку ноутбука. Сейчас сделан только локальный вариант.
